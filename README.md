# NexusAI - Next-Generation Cognitive & Autonomous Systems

> **Creative HTML & CSS Webpage Project (Group 3 - Project 7: AI Technology Website)**  
> Built strictly using **pure HTML5 and CSS3** (no JavaScript or other programming languages).

---

## 📋 Features

- **Futuristic Dark-Mode Aesthetic**: Custom radial glow orbs, glassmorphic cards (`backdrop-filter`), neon gradient typography, and glowing borders.
- **Hero & Live Benchmarks**: Real-time KPI metrics banner showcasing reasoning accuracy (99.4%), inference latency (&lt;14ms), and token throughput.
- **AI Products Suite**: Interactive showcase featuring *AgentCore Framework*, *OmniVision 3D*, *PulseEdge Quantized*, and *Aegis Guardrails*.
- **Technology & System Architecture**: Breakdown of distributed vector sharding, cognitive graph RAG, confidential enclaves, and dynamic context compaction.
- **Industry Applications**: Concrete use cases across Biopharma, Algorithmic Finance, Autonomous Robotics, and Aerospace.
- **Leadership & Research Team**: Profiles of prominent research scientists and systems engineers with avatar badges.
- **Enterprise API Access Form**: Fully styled request form with role selector, workload intent, and infrastructure notes.
- **100% Responsive Design**: Fluid layouts optimized across mobile devices, tablets, and wide desktop displays.

---

## 🛠️ Built With

- **HTML5**: Semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`, `form`).
- **CSS3**: CSS Grid, Flexbox, custom CSS variables, Google Fonts (`Space Grotesk` & `Inter`), responsive media queries, and pure CSS glassmorphic effects.
